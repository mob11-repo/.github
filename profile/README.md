# MOB11

MOB11 is a learning platform built around clear, accessible study content and tools that help students stay organized.

## Projects

- **[MOB11 iOS](https://github.com/mob11-repo/mob11-ios)** — Native iOS app built with SwiftUI.
- **[MOB11 Web](https://github.com/mob11-repo/mob11-web)** — Web platform for accessing and managing learning content.

## What we're building

MOB11 brings learning materials and useful study workflows together. The projects share a common backend and are developed to provide a consistent experience across platforms.

## Development

Each repository contains its own setup instructions, requirements, and contribution guidance. Please refer to the relevant project README before getting started.
